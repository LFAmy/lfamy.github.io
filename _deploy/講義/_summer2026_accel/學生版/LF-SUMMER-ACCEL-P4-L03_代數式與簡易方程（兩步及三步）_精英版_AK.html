L03 — 代數式與簡易方程（兩步及三步）

V2 精英版 · P4 暑假
SSPA：代數範疇 — 方程

🎯 解題通則

  1. 兩步方程：先加減（消常數項）→ 再除乘（消係數）
  2. 三步方程：先展開括號 → 再移項（記得變號）→ 最後除乘
  3. 應用題：設未知數 x → 列方程 → 解 → 代入驗算合理性

✏️ 例題 6 題完整解答

例題 1 (a)：$x + 8 = 25$
$x = 17$
兩邊 $-8$：$x = 25 - 8 = 17$。驗算：$17 + 8 = 25$ ✓
例題 1 (b)：列方程並求解（提示應用題自編）
因題目空泛，示範：原有 $\$50$，買了 $\$23$ 物品，剩多少？$x = 50 - 23 = 27$
練習用：先把文字問題轉為算式。
例題 2 (a)：$3x + 5 = 20$
$x = 5$
兩邊 $-5$：$3x = 15$。兩邊 $\div 3$：$x = 5$。驗算：$3 \times 5 + 5 = 20$ ✓
例題 2 (b)：列方程並求解
自編示範
例題 3 (a)：一個數的 3 倍減 7 等於 20
原數 $= 9$
設 $x$，$3x - 7 = 20$，$3x = 27$，$x = 9$。驗算：$3 \times 9 - 7 = 20$ ✓
例題 4 (a)：$\frac{x}{4} + 3 = 7$
$x = 16$
兩邊 $-3$：$\frac{x}{4} = 4$。兩邊 $\times 4$：$x = 16$。驗算：$16 \div 4 + 3 = 4 + 3 = 7$ ✓
例題 4 (b)：$3(x+2) = 2x+10$
$x = 4$
展開：$3x + 6 = 2x + 10$。移項：$3x - 2x = 10 - 6$，$x = 4$
例題 5 (a)：$4x - 7 = 2x + 11$
$x = 9$
移項（記得變號）：$4x - 2x = 11 + 7$ → $2x = 18$ → $x = 9$。驗算：$4(9) - 7 = 29$，$2(9) + 11 = 29$ ✓
例題 5 (b)：$3(x+2) = 2(x-1) + 10$
$x = 2$
展開：$3x + 6 = 2x - 2 + 10 = 2x + 8$。移項：$3x - 2x = 8 - 6$，$x = 2$。驗算：$3(4) = 12$，$2(1) + 10 = 12$ ✓
例題 6 (a)：小明年齡是弟弟 3 倍，兩人和 28。各多少歲？
弟弟 $7$ 歲，小明 $21$ 歲
設弟弟 $x$，$x + 3x = 28$，$4x = 28$，$x = 7$。驗算：$7 + 21 = 28$ ✓
例題 6 (b)：長方形周界 36 cm，長是闊 2 倍。長和闊？
闊 $6$ cm，長 $12$ cm
設闊 $x$，長 $2x$。周界 $= 2(長 + 闊) = 36$，$長 + 闊 = 18$，$2x + x = 18$，$x = 6$。驗算：$12 + 6 = 18$，$2 \times 18 = 36$ ✓

$3x - 7 = 20$ → $x = 9$
Q6 (必做)：$\frac{x}{4} + 3 = 7$
$x = 16$
$-3$：$x/4 = 4$，$\times 4$：$x = 16$
Q7 (必做)：$4x - 5 = 2x + 11$
$x = 8$
移項：$2x = 16$ → $x = 8$
Q8 (必做)：小明年齡是弟弟 3 倍，兩人和 28
弟弟 $7$，小明 $21$
$x + 3x = 28$ → $x = 7$
Q9 (挑戰⭐)：$3(2x-1) = 15$
$x = 3$
展開：$6x - 3 = 15$ → $6x = 18$ → $x = 3$
Q10 (挑戰⭐)：$\frac{x+2}{3} = 5$
$x = 13$
兩邊 $\times 3$：$x + 2 = 15$ → $x = 13$
Q11 (挑戰⭐)：甲乙共有 $120$，甲比乙多 $20$，各有多少？
乙 $50$，甲 $70$
設乙 $x$，甲 $x + 20$。$x + (x+20) = 120$，$2x = 100$，$x = 50$。驗算：$50 + 70 = 120$，$70 - 50 = 20$ ✓
Q12 (挑戰⭐⭐)：$7 - 2x = 3$
$x = 2$
移項：$-2x = 3 - 7 = -4$。$\div -2$：$x = 2$
⚠️ 注意 $-2x \div -2 = x$，變號要小心。
Q13 (挑戰⭐⭐)：一個數 5 倍等於 3 倍加 12
原數 $= 6$
$5x = 3x + 12$ → $2x = 12$ → $x = 6$
Q14 (挑戰⭐⭐⭐)：$2(x+5) = 3(x-1)$
$x = 13$
展開：$2x + 10 = 3x - 3$。移項：$10 + 3 = 3x - 2x$，$x = 13$。驗算：$2(18) = 36$，$3(12) = 36$ ✓
Q15 (挑戰⭐⭐⭐)：長方形周界 36，長是闊的 2 倍
闊 $= 6$ cm，長 $= 12$ cm
$2(長+闊) = 36$，$長+闊=18$。$2x + x = 18$ → $x = 6$

📊 教學總結 · 易錯提醒

  1. 移項變號：從一邊移到另一邊要變號（$+ \to -$，$\times \to \div$）
  2. 展開括號：每項都要乘，包括負號項。例：$-2(x-3) = -2x + 6$
  3. 負負得正：$\div -2$ 時兩邊都變號
  4. 應用題檢查：代入原方程驗算答案合理性（年齡、價格不能是負）
