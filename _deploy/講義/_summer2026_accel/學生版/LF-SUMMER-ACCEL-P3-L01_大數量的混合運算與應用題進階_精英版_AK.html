L01 — 大數量的混合運算與應用題進階

V2 精英版 · P3 暑假
SSPA：數範疇 — 應用

🎯 本課目標 · 解題策略

  1. 多步應用題：先拆解條件，再逐步列式計算
  2. 逆運算：知道「結果」反推「原來的數」（加用減、減用加）
  3. 檢查答案：代回題目驗算，或用估算判斷合理性
  4. 五位數排序：由高位開始逐位比較

✏️ 例題完整解答（共 12 條）

例題1 (a)：28 名學生參加，成人 580 元，兒童 390 元
$16240$ 元
$28 \times 390 = 10920$ 元；$580 + 10920 = 11520$ 元？
修正：老師1人$580$ + 學生28人$390$；$28 \times 390 = 10920$；$580 + 10920 = 11520$ 元

$29 \times 50 = 1450$ 元
例題2 (a)：一個數 + 4580 = 30000，求該數
$25420$
$30000 - 4580 = 25420$
例題2 (b)：一個數 − 12650 = 8750，求該數
$21400$

例題3 (a)：撥款 50000 購書，24 套 × 125 元，還剩多少
$47000$ 元

例題3 (b)：剩 47000 元全部買 47 元材料，最多可買幾套

$47000 \div 47 = 1000$ 套
例題4 (a)：$35892$, $39852$, $35982$ 由小至大

📝 課堂練習（共 15 題）

Q1 (必做)：動物園成人 320 元、兒童 180 元，劉老師帶 3 名學生
$860$ 元
$1$ 成人 $+ 3$ 兒童：$320 + 3 \times 180 = 320 + 540 = 860$ 元
Q2 (必做)：一個數 + 2560 = 10000
$7440$
逆運算：$10000 - 2560 = 7440$
Q3 (必做)：1000 元，買 4 本 128 元書 + 2 盒 95 元文具
$298$ 元
$4 \times 128 = 512$；$2 \times 95 = 190$；$512 + 190 = 702$；$1000 - 702 = 298$ 元
Q4 (必做)：圖書館原 38560 本，借出 12580，歸還 6780
$32760$ 本
$38560 - 12580 = 25980$；$25980 + 6780 = 32760$ 本
Q5 (必做)：一個數 − 3500 = 28900
$32400$
逆運算：$28900 + 3500 = 32400$
Q6 (必做)：甲超市 28650，乙比甲多 8700，總營業額
$66000$ 元
乙 $= 28650 + 8700 = 37350$；總 $= 28650 + 37350 = 66000$ 元
Q7 (必做)：$45678 + 32987 - 21543$
$57122$
$45678 + 32987 = 78665$；$78665 - 21543 = 57122$
Q8 (必做)：$100000 - 45678 + 23456$
$77778$
$100000 - 45678 = 54322$；$54322 + 23456 = 77778$
Q9 (⭐)：$67923$, $69732$, $69327$ 由小至大，並求最大最小之差
$67923 < 69327 < 69732$；差 $= 1809$
萬位同 6，比千位：$7,9,9$ → $67923$ 最小；$69732 - 67923 = 1809$
Q10 (⭐)：$\{2,3,5,7,8,9\}$ 各用一次組最大最小六位數，求差
最大 $987532$、最小 $235789$；差 $= 751743$
最大：高位取大數 $9,8,7,5,3,2$ → $987532$；最小：低位取小數 $2,3,5,7,8,9$ → $235789$；差 $= 751743$
Q11 (⭐)：A 比 B 多 50000，A+B=250000
$A = 150000$、$B = 100000$
$A = (250000 + 50000) \div 2 = 150000$；$B = 250000 - 150000 = 100000$
Q12 (⭐⭐)：A+B+C=250000，A 比 B 多 30000，B 比 C 多 20000
$A = 110000$、$B = 80000$、$C = 60000$
設 $C = x$，則 $B = x + 20000$，$A = x + 50000$；$3x + 70000 = 250000$；$x = 60000$
Q13 (⭐⭐)：保險箱密碼 — 十萬=6、萬=6−2、千=萬×2、百=千−4、十=最小雙數、個=最大單數
密碼 $= 648429$
十萬 $= 6$、萬 $= 4$、千 $= 8$、百 $= 4$、十 $= 2$（最小正雙數）、個 $= 9$（最大一位單數）→ $648429$
⚠️ 學生常見錯誤：「雙數最小」誤答 $0$；HK 小學多採 $2$ 為正整數範圍最小雙數
Q14 (⭐⭐⭐)：6 月收入 685000、支出 377500；7 月收入多 85000、支出少 26000，7 月盈餘
$418500$ 元
7 月收入 $= 685000 + 85000 = 770000$；7 月支出 $= 377500 - 26000 = 351500$；盈餘 $= 770000 - 351500 = 418500$ 元
Q15 (⭐⭐⭐)：六位數 A3789B − B3789A = 799992，A>B，求 A、B
$A = 9$、$B = 1$
$(A - B) \times 99999 = 799992$；$A - B = 799992 \div 99999 = 8$；因 $A,B$ 均為首位數（$A,B \geq 1$），唯一解 $(A,B) = (9,1)$；驗算 $937891 - 137899 = 799992$ ✓

Q5：$50987, 50789, 50978$ 由大至小
$50987 > 50978 > 50789$

Q7 (⭐)：A、B 都是六位數，A>B，A−B=68900，A+B=300000
$A = 184450$、$B = 115550$
$A = (300000 + 68900) \div 2 = 184450$（6 位 ✓）；$B = (300000 - 68900) \div 2 = 115550$（6 位 ✓）
⚠️ 題目原版 A+B=200000，會令 B=65550（5位數），違反「都是六位數」條件。已修正為 A+B=300000。
Q8 (⭐)：禮堂 25680 座位，第一批 9870 人，第二批 10560 人，還剩空位
$5250$ 個
$9870 + 10560 = 20430$；$25680 - 20430 = 5250$ 個空位
Q9 (⭐⭐)：$\{0,4,6,7,8,9\}$ 各一次組最大最小六位數（0 不做十萬位），求差
最大 $987640$、最小 $406789$；差 $= 580851$
最大：高位取大 → $9,8,7,6,4,0$ → $987640$；最小：首位取 $4$，其餘遞增 → $4,0,6,7,8,9$ → $406789$；差 $= 580851$
⚠️ 學生常見錯誤：最小數首位放 0（變 5 位數）；須將 0 放第二位
Q10 (⭐⭐)：飛機 A 飛 124850 km，B 飛 235960 km，共飛及相差
共 $360810$ km；差 $111110$ km
共 $= 124850 + 235960 = 360810$ km；差 $= 235960 - 124850 = 111110$ km

📊 教學總結 · 易錯提醒

  1. 進位/退位：五位數運算必須小心進位 1 與退位 1
  2. 混合運算順序：同級運算由左至右；先乘除後加減
  3. 逆運算：加用減、減用加；可用代入驗算
  4. 多步應用題：先抄已知條件，再列分步算式，避免「一步錯步步錯」
  5. 和差問題：兩數和差公式 $A=(和+差)\div 2$、$B=(和-差)\div 2$
🚨 標誌性陷阱 / 挑戰題解析：
  • 功課 Q7（已修正）：原題 A+B=200000 會令 B=65550（5 位數），違反「都是六位數」。改 A+B=300000 後兩數均為六位數。
  • 課堂練習 Q13：「雙數最小」採 2 為答案；0 在 HK 小學通常不視為正整數範圍
  • 課堂練習 Q15：A−B=8 但 A、B 都是首位數（≥1），排除 (8,0)，唯一解 (9,1)
  • 功課 Q9：含 0 的最小六位數，首位要放 4（次小），0 放第二位，否則變 5 位數
