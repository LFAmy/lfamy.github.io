📝 P3 升P4 精英版講義

1.大數量的混合運算與應用題進階 2.分數比較與加減（異分母進階） 3.面積專題：組合圖形的分割與填補 4.乘法速算與估算策略 5.小數的加減混合運算 6.三角形與四邊形分類 7.棒形圖閱讀與製作 8.暑期總測評 + 精英挑戰賽

📝 P4 升P5 精英版講義

1.分數乘除的綜合應用 2.小數乘除與循環小數（P5下預習） 3.代數式與簡易方程（兩步及三步） 4.面積：多邊形與組合圖形 5.體積與排水法（P5下預習） 6.速率進階：相遇與追及問題 7.百分數應用：折扣與利息（P5下預習） 8.暑期總測評 + 呈分試預備

📝 P5 升P6 精英版講義

1.圓的全面應用：弧長與扇形面積 2.比例與相似圖形 3.速率圖像與進階應用 4.一元一次方程應用 5.立體圖形與表面面積（P6下預習） 6.概率入門與樹形圖（P6下預習） 7.呈分試跨課題綜合攻略 8.終極呈分試模擬 + 弱項閉環方案

📝 P6 升中一 精英版講義

1.有向數與數線的全面運用 2.代數式化簡與方程應用 3.方程應用與文字題建模 4.百分數綜合應用 5.坐標系與方向進階 6.立體圖形與截面：柱體/錐體/球體（F1預習） 7.圓形圖與數據分析綜合 8.中學數學思維轉型 + 學習路線圖
