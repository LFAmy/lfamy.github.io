## 一、廣告帳戶設定

### 1.1 聚光平台開戶
```
步驟：
1. 登入 XHS 企業號後台 → 推廣中心 → 聚光平台
2. 完成企業認證 (需商業登記證)
3. 設定付款方式 (信用卡/Alipay HK)
4. 初始充值：HKD $3,000 (Month 1 測試預算)
```

### 1.2 像素/轉化追蹤設定
```
1. 在聚光平台建立轉化事件：
   - 「私信諮詢」：用戶發送私信
   - 「WhatsApp點擊」：點擊 WhatsApp 連結
   - 「試堂預約」：完成試堂預約表單
   - 「正式報名」：完成付款

2. 安裝追蹤代碼：
   在 lfacademyhk.com 安裝 XHS Pixel
   在 WhatsApp 連結加入 UTM 參數
   (整合 lf_tracking_engine.py)
```

## 三、信息流廣告 (Feed Ads) 詳解

### 3.1 廣告格式

```
格式 A: 圖文筆記 (靜態)
- 尺寸：1080×1440 (3:4)
- 標題：20 字以內
- 正文：200-500 字
- 圖片：1-9 張 (建議 3-5 張)
- CTA 按鈕：立即諮詢 / 了解更多

格式 B: 視頻筆記 (動態)
- 尺寸：1080×1440 (3:4) 或 1080×1920 (9:16)
- 時長：15-60 秒
- 開頭 3 秒必須有 hook
- 建議加字幕 (靜音觀看場景多)
```

### 3.2 素材創作規範

```
封面設計：
✅ 大字標題覆蓋 40-60% 畫面
✅ 高對比顏色 (深藍+金色+紅色)
✅ 一個核心數字/對比/問題
❌ 純文字無設計
❌ 模糊/低清圖片
❌ 過度濾鏡/不真實感

文案規範：
✅ 開頭 hook 在前 15 字
✅ 使用「你」直接對話
✅ 段落短 (2-3 句一段)
✅ 加入 emoji 增加可讀性
❌ 硬推銷語言 (「立即購買」「限時優惠」...)
❌ 過度使用大階/感嘆號
❌ 抄襲其他品牌文案
```

### 3.3 定向設定

```
基礎定向：
├── 性別：女性
├── 年齡：28-45
├── 地區：香港 (全區)
└── 語言：繁體中文

興趣定向：
├── 一級興趣：教育、親子
├── 二級興趣：補習、小學教育、升學、考試
└── 擴展興趣：家庭教育、兒童發展

行為定向：
├── 曾搜索：補習、數學、呈分試、SSPA
├── 曾互動：教育類筆記、補習類筆記
└── 設備：iPhone 用戶優先 (XHS 主流)

排除：
└── 已報名學生家長 (如有名單)
```

## 五、預算與出價策略

### 5.1 月度預算規劃

```
Month 1 (6月)：HKD $5,000
├── 信息流：$3,000 ($100/日)
├── 搜索：$1,000 ($33/日)
├── 筆記加熱：$500 (測試用)
└── 直播：$500 (2場 × $250)

Month 2 (7月)：HKD $8,000
├── 信息流：$4,500 ($150/日)
├── 搜索：$2,000 ($66/日)
├── 筆記加熱：$1,000
└── 直播：$500

Month 3 (8月)：HKD $12,000
├── 信息流：$7,500 ($250/日)
├── 搜索：$3,000 ($100/日)
├── 筆記加熱：$1,000
├── KOC合作：$500
└── 直播：$0 (有機直播)
```

### 5.2 出價策略時間線

```
Phase 1 (Day 1-7)：自動出價
→ 讓系統學習，不設限
→ 觀察 CPC 範圍

Phase 2 (Day 8-14)：手動 CPC
→ 信息流：設定上限 CPC $3-5
→ 搜索：設定上限 CPC $5-8

Phase 3 (Day 15+)：目標 CPA
→ 設定目標 CPA：$80/試堂預約
→ 系統自動優化

優化規則：
- CTR < 2% → 暫停廣告，更換素材
- CPC > $10 → 降低出價或更換定向
- CPA > $120 → 檢查漏斗，優化落地頁
- ROAS < 2x (Month 3後) → 重新評估策略
```

## 六、AB 測試矩陣

### 6.1 測試項目排程

```
測試 #1 (Week 2-3)：標題風格
├── A: 痛點型 「你小朋友係咪成日錯同一類題？」
├── B: 數據型 「研究證實：90%小學生數學錯係同一陷阱」
├── C: 故事型 「試過3間補習社都冇效，直到發現呢個真相」
└── 指標：CTR (點擊率)

測試 #2 (Week 3-4)：封面設計
├── A: 陷阱示範型 (紅筆圈出錯誤答案)
├── B: 數據圖表型 (大數字+圖表)
├── C: 人物情感型 (真實媽媽/小朋友照片)
└── 指標：CTR + 互動率

測試 #3 (Week 4-5)：CTA 風格
├── A: 直接型 「留言『試堂』立即預約」
├── B: 引導型 「你小朋友邊個課題最弱？留言話我知」
├── C: 價值型 「留言『診斷』免費攞陷阱速查卡」
└── 指標：留言率 + 私信率

測試 #4 (Week 5-6)：發佈時間
├── 對照：當前最佳時間
├── 測試：偏移 ±1 小時
└── 指標：發布後 1 小時互動量

測試 #5 (Month 2)：視頻 vs 圖文
├── A: 靜態圖文筆記
├── B: 15-30秒短視頻 (同一內容)
└── 指標：互動率 + 收藏率
```

### 6.2 AB 測試執行規範

```
規則：
1. 每次只測試 1 個變量
2. 每個變體最少 $100 預算
3. 最少跑 5 天收集數據
4. 樣本量 > 5,000 曝光才下結論
5. 勝出者自動成為下一輪對照組
6. 記錄所有測試結果於 ab_tests.json
```

### 7.2 警報閾值

```
🔴 紅色警報 (立即處理)：
- 花費 > 預算 120% 無轉化
- CTR < 1% 持續 3 天
- CPA > $150

🟡 黃色注意 (24小時內檢查)：
- CTR 下降 > 30% 日比日
- CPC 上升 > 50%
- 某廣告組花費集中 > 60%

🟢 綠色正常：
- CPA < $80
- CTR > 3%
- ROAS > 3x
```
