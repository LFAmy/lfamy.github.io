## 🔥 三、爆款筆記公式

### 標題公式 (從研究提煉)

```
公式 1: 數字 + 痛點 + 結果
「3個步驟，P5數學呈分試由60分變90分」

公式 2: 反直覺 + 數據
「研究證實：暑假唔溫數學 = 倒退2.6個月」

公式 3: 問題 + 共鳴
「你小朋友係咪成日錯同一類題？90%家長唔知嘅真相」

公式 4: 對比 + 情感
「試過3間補習社都冇效  vs  8堂就睇到變化」

公式 5: 場景 + 緊急感
「P5媽媽注意：你以為仲有2年，其實得返1年」
```

### 封面設計黃金法則

```
- 3:4 比例 (1080×1440) 佔據最大屏幕空間
- 大字標題覆蓋 40-60% 畫面
- 顏色：深藍 (#1A3C6D) + 金色 (#C9A84C) + 紅色 (#DC2626)
- 必須有：一個大字數字 / 一個對比 / 一個情緒詞
- 嚴禁：純文字封面 / 模糊圖片 / 過度濾鏡
```

### 文案結構 (SCQA + CTA)

```
S (情境) → C (衝突) → Q (問題) → A (答案) → CTA

例：
S: 「P5下學期嘅數學，開始教分數乘除法...」
C: 「但好多小朋友連基本分數加減都未搞掂」
Q: 「點解會咁？因為冇人幫佢搵出陷阱盲點」
A: 「我哋嘅10大陷阱診斷，65分鐘就知佢邊度出事」
CTA: 「留言『診斷』，免費幫你小朋友做一次」
```

   每個講義可拆出 3-5 條 XHS 筆記

3. AI 自動化基建 → 極低成本營運
   現有 content_v3 + smart_publisher = 基礎已打好

4. 香港在地品牌 → 不能被複製的本地信任
   港式廣東話 + 香港考試制度理解 = 壁壘

5. 生產級工程模式 → 品質保證
   API-First + 品質閘道 = 每篇內容經過驗證
```

→ 我們的優勢：系統化內容策略 + AI 自動化

→ 規模大，但不懂香港市場和 SSPA 制度
→ 我們的優勢：本地化 + 港式語言 + SSPA 專業

替代方案：家長自教 / 學校老師
→ 我們不是要取代，是補充專業診斷
→ 定位：家長嘅「診斷專家」而非純補習老師
```

def xhs_quality_gate(note):
    checks = {
        '標題 < 20 字': len(note['title']) <= 20,
        '含數字或情緒詞': any(c.isdigit() for c in note['title']) or any(w in note['title'] for w in ['震驚','恐怖','真相','必看','秘密']),
        '封面 3:4 比例': note['image_ratio'] == '3:4',
        '文案含 SCQA 結構': all(w in note['body'] for w in ['情境','衝突','問題','答案'][:2]),
        '含互動誘餌': '留言' in note['body'] or '投票' in note.get('type',''),
        '#標籤 5-15 個': 5 <= len(note['hashtags']) <= 15,
        '內容指紋無重複': not is_duplicate(note['body']),
        '已排程時間': note.get('scheduled_time') is not None,
    }
    return all(checks.values()), checks
