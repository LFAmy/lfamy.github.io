## 內容生產 SOP

### 每週內容生產流程

```
週四：規劃下週主題線 + 選定 28 篇內容主題
週五：AI 生成初稿 (用 lf_ai_content_engine.py)
週六：人工審核 + 調整文案 + 設計圖片
週日：排程設定 + 品質閘道檢查
週一-日：自動發布 + 實時互動
```

### 內容重用矩陣

```
1 個講義 → 多篇筆記：
├── 陷阱解密帖 (核心知識)
├── 互動測驗帖 (投票/問答)
├── 方法乾貨帖 (口訣/技巧)
├── 數據衝擊帖 (考試佔比)
└── 真實故事帖 (學生案例)

172 講義 × 5 帖 = 860 帖潛在內容
足夠 215 天 (7+ 個月) 不重複
```
