## 三、廣告素材規格

### 3.1 Reels 廣告 (最優先)

```
格式: 9:16 直向影片
長度: 15-30 秒
技術: MP4, H.264, 30fps

Hook 模式 (頭 3 秒):
├── 「你小朋友做緊呢題數嘅時候...」 (好奇心)
├── 「90% 家長都唔知嘅呈分試秘密...」 (資訊缺口)
├── 「呢條數，你做啱咗未？」 (挑戰)
├── 「只需 15 秒，學識小數除法」 (價值承諾)
└── 「見到呢條題目，好多小朋友即刻...」 (故事)

內容架構:
├── 0-3秒: Hook
├── 3-10秒: 核心教學/價值
├── 10-13秒: 社會證明/成果
├── 13-15秒: CTA + 品牌
└── 全程字幕

每週製作: 3-5 條
```

### 3.2 輪播廣告 (Carousel)

```
格式: 1:1 方形圖 (1080×1080)
卡數: 3-5 卡

卡片策略:
├── 卡1: 痛點 (Hook)
├── 卡2: 解決方案 (LF 方法)
├── 卡3: 證明 (成果/數據)
├── 卡4: 優惠/CTA
└── 卡5: (可選) 品牌/聯絡

適用: 免費資源下載 / 課程介紹 / 品牌故事
```

### 3.3 即時表格廣告 (Lead Gen)

```
格式: 單圖 (1:1) 或 影片
CTA: 「立即下載」/「免費領取」

表格欄位 (越少越好):
├── 必填: Email
├── 選填: 小朋友年級
├── 選填: 最擔心課題
└── 不要: 電話 (降低轉化)

自訂感謝頁面:
「下載連結已發送到您的 Email！
同時邀請加入我們的家長互助社團 → [連結]」
```

### 3.4 單圖廣告 (Conversion)

```
格式: 1:1 (1080×1080) 或 1.91:1 (1200×628)
文案: 長文案 (含社會證明+保證+CTA)

標題公式:
├── 「{數字} + {形容詞} + {結果}」
├── 例: 「172 講義 + AI 診斷 = 數學成績提升一級」
└── 例: 「90% 家長推薦的呈分試數學方案」

主要文字 (Primary Text) 結構:
├── 開場: 痛點共鳴
├── 中間: 方案介紹 (3 要點)
├── 證明: 數據/見證
├── 保證: 退款/試堂保證
└── CTA: 明確下一步
```
